# 💙 MindCare AI — Mental Health Awareness & Suicide Prevention Agent

> **Powered by IBM Granite + IBM WatsonX | IBM Cloud Project**

⚠️ **DISCLAIMER**: This AI is a support and awareness tool ONLY. It is **NOT** a substitute for professional medical advice. For immediate crisis support, call **988** (US) or text **HOME to 741741**.

---

## 🌟 Overview

MindCare AI is an **Agentic AI-powered Mental Health Awareness & Suicide Prevention Agent** built for IBM's Problem Statement #2. It combines IBM Granite's language understanding with a Retrieval-Augmented Generation (RAG) system to provide empathetic, safe, and proactive mental health support.

### Key Capabilities

| Feature | Description |
|---|---|
| 🧠 **Empathetic Conversation** | IBM Granite-powered chat with trauma-informed, person-centered responses |
| 🔍 **Distress Detection (RAG)** | Multi-tier keyword + semantic retrieval detects risk from low → critical |
| 📈 **Risk Prediction** | Weighted rolling average + linear trend analysis forecasts stress peaks |
| 📖 **Journal Analysis** | AI analyzes free-text journal entries for emotional themes & risk signals |
| 🌱 **Wellness Plans** | Personalized 7-day plans generated by IBM Granite |
| 🆘 **Crisis Intervention** | Automatic crisis resource delivery for high/critical risk detection |
| 🔗 **Resource Hub** | Curated helplines (US, India, UK, AU, Global), therapy platforms, apps |

## 🚀 Quick Start

### Prerequisites
- Node.js 18+
- IBM Cloud account with WatsonX access

### Installation

```bash
# Install dependencies
npm install

# Run tests (no API call needed)
npm test

# Start the server
npm start
```

The app will be available at **http://localhost:3000**

### Configuration

Edit `config.env`:
```env
IBM_API_KEY=your_ibm_api_key
IBM_PROJECT_ID=your_project_id
IBM_GRANITE_MODEL=ibm/granite-3-3-8b-instruct
IBM_WATSONX_URL=https://us-south.ml.cloud.ibm.com
PORT=3000
```

## 📡 API Reference

### Chat
```
POST /api/chat
Body: { sessionId, message }
Returns: { response, riskLevel, isCrisis, alert, resources, sessionStats }
```

### Journal Analysis
```
POST /api/journal/analyze
Body: { sessionId, journalText }
Returns: { analysis: { emotional_themes, risk_level, empathetic_reflection, ... } }
```

### Wellness Plan
```
POST /api/wellness/plan
Body: { sessionId, preferences: { focus: [...] } }
Returns: { plan: "7-day plan text" }
```

### Session Analytics
```
GET /api/session/:sessionId/summary
GET /api/session/:sessionId/trend
GET /api/session/:sessionId/history
```

### Resources
```
GET /api/resources/helplines?country=us|india|uk|australia
GET /api/resources/crisis
GET /api/resources/therapy
GET /api/resources/apps
GET /api/resources/recommend?riskLevel=high
GET /api/resources/knowledge?category=depression
```

### Consent & Monitoring
```
POST /api/session/:sessionId/consent
Body: { consent: true }
```

## 🛡️ Risk Level System

| Level | Score | Examples | Response |
|---|---|---|---|
| **None** | 0 | General conversation | Standard support |
| **Low** | 25 | Sad, lonely, tired | Gentle coping tips |
| **Medium** | 50 | Depression, anxiety, panic | Coping strategies + therapy suggestion |
| **High** | 75 | Hopelessness, trapped, worthless | Immediate resources + crisis options |
| **Critical** | 100 | Suicidal ideation, self-harm | Crisis hotlines IMMEDIATELY |
